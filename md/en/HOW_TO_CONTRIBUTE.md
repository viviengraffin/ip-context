# How to contribute?

## As a developer

As a developer, you must first install Bun on your computer.

The command to use to install Bun is located [here](https://bun.com/)

Once Bun is installed, you must clone this repository :

```sh
git clone git@github.com:viviengraffin/ip-context.git
```

After that, you must type this command in the project directory:

```sh
bun install
```

You will have access to the following commands:

- bun run bench : Runs a performance test
- bun run test : Runs the unit tests
- bun run test:watch : Executes unit tests during development
- bun run build : Build versions for web and npm
- bun run build:web : Build web versions
- bun run build:npm : Build npm version

From here, you can contribute to the development of this library.
