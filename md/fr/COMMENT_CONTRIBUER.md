# Comment contribuer ?

## En tant que développeur

En tant que développeur, vous devez d'abord installer Bun sur votre ordinateur.

La commande à utiliser pour installer Bun se trouve [ici](https://bun.com/)

Une fois Bun installé, vous devez copier ce dépot. Pour ce faire, tapez la commande suivante :

```sh
git clone git@github.com:viviengraffin/ip-context.git
```

Ensuite, vous devez tapez cette commande dans le répertoire du
projet :

```sh
bun install
```

Vous aurez accès aux commandes suivantes:

- bun run bench : Fait un test de performance
- bun run test : Éxecute les tests unitaires
- bun run test:watch: Éxecute les test unitaires pendant le développement
- bun run build : Construit les versions web et npm
- bun run build:web : Construit les versions web
- bun run build:npm : Construit la version npm

À partir de là, vous pourrez contribuer au développement de cette bibliothèque.
